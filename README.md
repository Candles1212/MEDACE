# MEDACE

A modern offline-first Android learning app for Class 12 and MDCAT preparation.

## Planned subjects
- Biology
- Chemistry
- Physics
- English
- Logical Reasoning

## Planned features
- Chapter-wise MCQs and practice tests
- Mock exams with results and explanations
- Flashcards and a mistake notebook
- Study planner and progress analytics
- Notes and formula library
- Offline-first study support

## Development
The app is being built with Flutter and Dart, with local storage for offline learning.

## Status
Initial project setup in progress. Features will be added and tested incrementally.
