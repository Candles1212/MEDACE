# MEDACE

MEDACE is an offline-first Flutter Android study app for Class 12 and MDCAT preparation.

## Official syllabus map
The app currently maps the five PM&DC MDCAT subjects into 61 syllabus units:
- Biology — 16 units (45% / 81 questions in the official paper)
- Chemistry — 20 units (25% / 45 questions)
- Physics — 16 units (20% / 36 questions)
- English — 3 competency areas (5% / 9 questions)
- Logical Reasoning — 6 competency areas (5% / 9 questions)

The syllabus reference is the PM&DC Uniform Curriculum MDCAT 2025, listed on the official PM&DC syllabus page. Check PM&DC for any later replacement before an exam sitting.

## Current app features
- Subject and unit explorer with topic/subtopic checklists.
- Topic-filtered MCQ practice.
- Answer checking and explanations.
- Difficulty labels and practice score.
- Starter bank of 20 original MCQs.

## Question bank plan
The long-term target is 10,000+ original, reviewed MCQs. Questions are authored in batches and mapped to a subject and syllabus unit. The target is not yet complete; the current count is the starter bank count shown in the app. Questions should be original and concept-aligned, not copied from copyrighted textbooks or commercial question banks.

## Development
- Flutter / Dart
- Offline content bundled with the app
- GitHub Actions builds an Android release APK on pushes to `main`
